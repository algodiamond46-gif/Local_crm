CRM לוקאלי בעברית - הוראות מהירות

מה המערכת עושה:
- ניהול לידים בעברית
- סטטוסים לצינור מכירה
- תיעוד שיחות והערות
- follow up עם תאריך ושעה
- קליטת לידים דרך API מהאתר או מפייסבוק דרך webhook

איך מפעילים:
1. מתקינים Python 3.11 או 3.12
2. פותחים את התיקייה
3. לוחצים פעמיים על start_crm.bat
4. בדפדפן נכנסים לכתובת:
   http://127.0.0.1:5050

איך לחבר טופס באתר:
שלח POST לכתובת:
http://127.0.0.1:5050/api/leads

דוגמת JSON:
{
  "name": "ישראל ישראלי",
  "phone": "0500000000",
  "email": "lead@example.com",
  "source": "אתר",
  "notes": "השאיר הודעה בטופס"
}

איך לחבר Facebook Leads:
- הדרך הפשוטה ביותר היא דרך Make או Zapier
- מגדירים Trigger של Facebook Lead Ads
- Action: Webhook / POST
- שולחים לכתובת:
  http://127.0.0.1:5050/api/leads

חשוב:
אם רוצים שפייסבוק או האתר יכניסו לידים כשאתה לא על אותו מחשב, צריך או:
1. להשאיר את המחשב דלוק ולפתוח גישה דרך ngrok / Cloudflare Tunnel
או
2. להעלות את אותה מערכת לשרת בהמשך

שדות מומלצים מהפייסבוק:
- name
- phone
- email
- source = Facebook
- notes
